# 小模型受限实验协议 v2

该版本替代 `real_transport_multiseed_protocol_v1` 的**后续执行**，原因是 30B 本地模型加载造成工作站明显资源压力。v1 的文件不删除，以保留可审计的运行历史；其中 30B 的已完成和中断轨迹均从本协议的评分、汇总与解释中排除。

允许模型严格限于：`qwen3:0.6b`、`llama3.2:1b` 与 `qwen2.5vl:3b`。本机登记的模型文件大小分别约为 0.522 GB、1.3 GB 和 3.2 GB，均不超过 4 GB 上限。每个响应都用 `keep_alive=0` 立即卸载，防止三个小模型被 Ollama 同时保留在 GPU 内存中。禁止启动 `qwen3-vl:30b-a3b-instruct-q4_K_M`、大模型健康检查或并行本地模型执行。

仍使用 15 个冻结真实跨层级硬负例、两个固定 Schema 条件、温度 0、1600 token 上限和两个新增种子 `20260915`、`20260916`。原先 `20260914` 的三种允许小模型轨迹可作为重用基线，但必须在评分时显式按模型过滤，以排除同目录里的 30B 轨迹。

新种子使用单独的 `*_small_v2_serial_seed*` 输出目录，绝不与已有的部分 30B 或未立即卸载的目录混写。每个新种子与条件产生 `3 × 15 = 45` 条轨迹；完整设计为 3 个种子 × 2 条件 × 3 模型 × 15 包。它仍只有一个依赖来源簇，不能解释为生物学样本量或模型排名。
