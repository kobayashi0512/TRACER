# 因子化合成安全基准 v2

此基准是 TRACER 的确定性实现验证，不包含患者数据、真实机制结论或模型排名。

它穷举五个二元数据层条件，构成 `2^5 = 32` 个冻结证据包：

- 运输条件是否成立：相同可用于复制的测量层级和生物学区室；
- 三个关联队列是否具有至少两个经过审计的独立来源组；
- 每一个复制队列的 FDR 是否均不高于 0.05；
- 是否存在方向一致的扰动证据；
- 分析性证据是否均标注为已评估批次与组成混杂。

每个包都用一个完整引用的确定性草稿评估一次。只有五个条件均成立时，冻结参考标准允许高优先级。该标准不是“真实生物学是否为真”的标签，而是本项目事先规定的准入协议。

证据溯源覆盖不被伪装为第六种生物医学证据。对每个包，程序额外制造一个漏掉 `literature-2` 的草稿，并比较完整 TRACER 与关闭 `provenance_coverage` 模块的反事实。因此共形成 32 × 3 = 96 次确定性评估：完整草稿、漏引草稿、以及漏引但关闭覆盖模块的草稿。

同一套件还以完整草稿关闭 `transport_aware_replication` 门。唯一会被该反事实错误升为高优先级的包是：其他四项条件均通过、但测量层级/区室运输不合格的情形。这个计数是算法实现性质，不是模型失误率或生物学发现。

来源独立性与全队列 FDR 也使用同一原则单独消融。关闭来源门时，比较器天真地把三个队列标签当成独立来源；关闭 FDR 门时，比较器退回旧的两个 FDR 槽位而忽略第三个队列。对于每一个门，只有“该门失败而其余四项通过”的一个固定包可被错误升为高优先级。所有消融都是评估比较器，绝不能用于部署或研究优先级判断。

最后加入一个朴素计数式比较器：它按队列名称计数、只看首两个 FDR，并池化运输不匹配的队列，同时不强制全证据引用。在完整引用草稿中，它会把五项因子中的运输、来源独立性和第三队列 FDR 全部忽略；因此当扰动与混杂两项通过时即可升为高优先级。该比较器的预设错误升级计数为 7 个，旨在说明完整证据图门控相对于简单“两个队列 + 两个显著 FDR”的增量保护，而不是模拟一种临床决策规则。

未来模型实验只先运行清单中预注册的 12 个包：全通过控制、五个单因子失败、以及六个指定的双因子交互。它们用于发现实现/提示问题；完整的 32 包仍保留给算法验证。任何 LLM 结果都按同一个 `SYNTHETIC_FACTORIAL_V2` 依赖簇报告，不能把包或模型回复当作独立生物医学样本。
