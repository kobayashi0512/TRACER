# Synthetic TRACER stress-test packets v1

These packets are deliberately synthetic algorithm tests. They use fictional cohort IDs and source identifiers, contain no patient data, and must never be presented as biomedical results, clinical evidence, or external validation.

They isolate six pre-specified evidence structures: complete eligible evidence, cross-modality pseudo-replication, selective omission risk, absent perturbation, unresolved confounding, and single-cohort evidence. The evaluator-only reference standard is removed before any LLM prompt is rendered.
